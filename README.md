# Mahak & Raviraj Wedding Invitation

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. In Terminal run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite (normally http://localhost:5173).

## Included
- Reference-style invitation opening screen with envelope and wax seal.
- Invitation section, Ganesh illustration, names, countdown, five event cards, gallery, family, venue, contacts and footer.
- Original generated instrumental loop. It starts when the envelope is clicked.
- Fixed bottom-right mute/unmute button.

## Personalize
Edit `wedding` and `events` near the top of `src/main.jsx`. Replace family names, wedding date, venue, map query and phone numbers. Replace gallery sample URLs with the couple's photos.

The instrumental track is an original synthesized instrumental created for this template, not the original audio from the reference site.
